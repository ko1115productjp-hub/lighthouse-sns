# Project: "Lighthouse of Intellect" (仮称) - 知の永久アーカイブ・プラットフォーム
## 核心思想・プロトコル定義書

### 1. サービス・コンセプト
本プラットフォームは、単なるSNSではなく「人類の知の地層」を形成するためのパブリック・アーカイブである。
「誰が言ったか」という権威性を徹底的に排除し、出力された内容の「独自性」「新規性」「一次性」のみを、LLMとコミュニティによる査読を通じて評価し、永続化する。

### 2. 基本原則 (The Core Tenets)
- **客観的評価の至上主義:** 投稿者の実績やフォロワー数に関わらず、内容の論理整合性と希少性のみを価値尺度とする。
- **無自覚な貢献の称揚:** ユーザーが「価値がある」と自覚していなくとも、システムが客観的に知の財産と判断したものは、人類の資産として昇格させる。
- **改ざん不可能な履歴:** すべての投稿、修正、批判はハッシュ化され、変更履歴（差分）を含めて永久に保存される。ユーザーが退会しても、知の系譜からその出力が消えることはない。
- **18歳以上の聖域:** 責任ある言論と、論理的整合性を担保するための年齢制限。

### 3. LLM査読・判定ロジック (The Scoring Engine)
LLMは「平均的な正解」を出す装置ではなく、「平均からの乖離」を検知するセンサーとして機能する。

- **乖離度 (Divergence):** 既存のWebデータや標準的なAI回答から、意味ベクトルがどれだけ離れているか。
- **内部密度 (Density):** 乖離した「特異点」において、具体的かつ論理的な補強（5W1H、微細な観察、矛盾する感情等の一次情報）がどれだけ集中しているか。
- **逆シミュレーション:** 別のLLMに続きを書かせ、AIが予測できない「人間固有の執着・跳躍」が含まれているかを検証。
- **AI生成物の許容:** AIを用いた創作であっても、人類の知に貢献する「独自性」があれば正当にアーカイブする。

### 4. インセンティブ・エコシステム
- **引用による権威:** 「いいね」ではなく「被引用数（どれだけ後の知の土台になったか）」でレコメンドを決定。
- **批判の価値化:** 正当な批判によって作品を磨いた者は「共同貢献者 (Contributor)」として履歴に名を刻む。
- **称号とキャッチコピー:** 実績に応じLLMが「論理の外科医」「未踏地の観測者」等の二つ名を授与。ただし、これは審査のショートカット権限を与えない。

### 5. フィードバック・コーチング
- **不採用時のメンター機能:** 独自性不足や一次情報の欠如に対し、LLMが「なぜ届かなかったか」を論理的に解説し、再挑戦のための「問い」を提示。
- **知のジム化:** 投稿を通じて、ユーザーの論理的思考と文章解像度を強制的に引き上げる。

### 6. 公平性の美学 (Anti-Authority Bias)
- **ブラインド審査:** 査読段階では投稿者の属性を完全遮断。
- **ジャイアント・キリング:** 無名な新人の「狂気」が、既存の「権威」の矛盾を突いた場合、それを歴史的転換点としてシステムが公式に記録する。

### 7. 永続化プロトコル
- 投稿時、ユーザーは「パブリック化（ハッシュチェーン連結）された情報の削除不可」に同意する。
- 全ての知見は、個人の所有物から「人類の共有資産」へと移行するプロセスを辿る。
